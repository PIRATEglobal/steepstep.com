# System Overview

## Status

PROPOSED. This is a venture assessment. No production system has been approved.

## Scope

The future system may include patient acquisition, booking and payment, secure remote consultations, practitioner workflows, patient records, communications, and outcome tracking. The exact architecture is unresolved until the legal and clinical operating model is established.

## Constraints to resolve

- Country specific healthcare and professional practice rules.
- Health data protection, retention, access, and hosting requirements.
- Clinical safety, escalation, emergency handling, and documentation.
- Payment, refund, and package entitlement behavior.

Any implementation plan must first establish the applicable rules and data ownership boundaries.
